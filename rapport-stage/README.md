# Rapport de stage — ATLASYN Insight

- `Rapport-de-stage-ATLASYN-Insight.pdf` : version finale prête à relire et imprimer (51 pages) ;

- `assets/` : captures originales de l’application ATLASYN Insight.

## À personnaliser impérativement

Les champs jaunes entre crochets doivent être remplacés avant le dépôt :

- votre nom, matricule, classe, filière et établissement ;
- l’organisme d’accueil, son activité, son service et sa localisation ;
- le type et les dates exactes du stage ;
- les noms et fonctions des encadrants ;
- les missions réellement effectuées et le calendrier réel du stage ;
- les signatures et logos officiels demandés par votre établissement.

Utilisez la recherche `[` dans le fichier HTML pour parcourir rapidement tous les champs à compléter.

Pour le journal, remplacez également les 30 dates et horaires. Si certains jours correspondent à un repos, un congé ou une absence, indiquez-le honnêtement dans l’entrée concernée et dans la feuille de suivi finale.

## Produire un nouveau PDF

1. Ouvrez `rapport-stage-atlasyn.html` dans un éditeur et remplacez les champs jaunes.
2. Ouvrez ensuite le fichier dans Google Chrome.
3. Choisissez **Imprimer → Enregistrer au format PDF**.
4. Conservez le format A4, activez les graphismes d’arrière-plan et désactivez les en-têtes/pieds de page du navigateur.
5. Vérifiez la couverture, le sommaire et les numéros de pages avant le dépôt.
